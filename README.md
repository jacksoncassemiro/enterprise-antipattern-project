
# Enterprise AntiPattern Project

Projeto enterprise propositalmente construído com ANTIPADRÕES de:

- Clean Code
- SOLID
- Arquitetura
- Design
- Escalabilidade
- Manutenibilidade

## Objetivo

Projeto ideal para:
- Aula prática de refatoração
- Code Review
- Treinamento de liderança técnica
- Exercícios de arquitetura
- Identificação de débito técnico
- Workshop de Clean Code
- Exercícios de Design Patterns

## Antipadrões existentes

- God Class
- God Method
- Alto acoplamento
- Baixa coesão
- Dependência concreta
- Métodos gigantes
- Variáveis sem significado
- Código duplicado
- If/Else Hell
- Falta de interfaces
- Violação de SRP
- Violação de OCP
- Violação de DIP
- Falta de testes
- Regras de negócio espalhadas
- SQL hardcoded
- Logs ruins
- Tratamento de erro inexistente
- Falta de separação de camadas
- Código procedural
- Números mágicos
- Classes com múltiplas responsabilidades

## Exercícios sugeridos

1. Aplicar SOLID
2. Criar arquitetura em camadas
3. Aplicar Clean Architecture
4. Criar testes unitários
5. Aplicar Repository Pattern
6. Extrair serviços
7. Melhorar nomenclatura
8. Remover duplicação
9. Reduzir complexidade ciclomática
10. Criar interfaces
